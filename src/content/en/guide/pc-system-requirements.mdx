The official Crimson Moon PC system requirements are live on the Steam page, and they are moderately demanding: the minimum asks for a **GTX 1070-class GPU, 16 GB of RAM, and Windows 11**, while the recommended tier doubles the memory and jumps to an RTX 3070. Both tiers need **DirectX 12** and **50 GB of storage**.

## Minimum Requirements

| Component | Spec |
|---|---|
| OS | Windows 11 (64-bit required) |
| Processor | Intel Core i5-8400 / AMD Ryzen 5 2600 |
| Memory | 16 GB RAM |
| Graphics | Nvidia GeForce GTX 1070 / AMD Radeon RX 5700 / Intel Arc A580 |
| DirectX | Version 12 |
| Storage | 50 GB available space |
| Sound | Surround Sound |
| VR | Not supported |

## Recommended Requirements

| Component | Spec |
|---|---|
| OS | Windows 11 (64-bit required) |
| Processor | Intel Core i7-10700K / AMD Ryzen 5 5600X |
| Memory | 32 GB RAM |
| Graphics | Nvidia GeForce RTX 3070 / AMD Radeon RX 6700 XT / Intel Arc A770 |
| DirectX | Version 12 |
| Storage | 50 GB available space |

## Notes for PC Players

The spec sheet is Windows 11-only on paper, and the 50 GB footprint is on the larger side for a $19.99 title. Intel Arc GPUs are explicitly supported at both tiers, which is still unusual. Console players (PS5, Xbox Series X|S) don't need to worry about any of this — see [release date and platforms](/release/release-date-and-platforms) for the console picture.
